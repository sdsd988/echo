# echo 프롬프트 가이드 — 4-1 컨텍스트 계층

> **진입:** `git checkout v4.1-baseline`
> 아래 프롬프트를 **순서대로** Claude Code에 붙여넣으세요. 결과로 `CLAUDE.md`와 `.claude/rules/`가 생깁니다.
> Claude 응답은 매번 조금씩 다릅니다 — 결과가 안내와 다르면 한 번 더 시키거나 직접 다듬으면 됩니다.

---

## S1 — /init으로 CLAUDE.md 처음 만들기

빈 프로젝트를 스캔해 `CLAUDE.md` 초안을 자동 생성합니다. (Claude Code 내장 명령)

```
/init
```

---

## S2 — CLAUDE.md를 '헌법'으로 다듬기

자동 생성본은 길고 장황할 수 있습니다. 매 턴 자동 로드되는 파일이니 **짧고 핵심만** 남깁니다.

```
방금 만든 CLAUDE.md를 다듬어줘. 이건 매 턴 자동으로 컨텍스트에 들어가는 파일이라
짧고 핵심만 있어야 해. 아래만 남기고 나머지 군더더기는 빼줘:
- 프로젝트 한 줄 소개 (Threads류 텍스트 SNS 백엔드)
- 기술 스택 (Java 25, Spring Boot 3.5.x, Gradle 멀티프로젝트, H2, JUnit 5)
- 멀티모듈 구조 (apps/customer-api, modules/post, modules/user, common)
- 핵심 규칙: 의존성 방향(apps→modules,common / modules→common / 모듈 간 직접 의존 금지),
  각 모듈 hexagonal(domain/application/infrastructure), 도메인 모듈은 Spring Web 의존 없음(POJO+JPA),
  DTO는 record, 패키지는 com.echo.{module}.{layer}
- 빌드/실행 명령
- 응답은 한국어로
```

---

## S3 — post 모듈 규칙을 .claude/rules/로 분할 (paths 스코프)

도메인 세부 규칙은 CLAUDE.md에 다 넣지 않습니다. **그 모듈을 만질 때만** 로드되도록 `paths:`를 겁니다 — 토큰 예산 절약.

```
post 모듈에만 적용되는 세부 규칙을 .claude/rules/post.md로 분리해줘.
frontmatter에 paths를 걸어서 modules/post/** 와 apps/customer-api의 post 관련 파일을
만질 때만 로드되게 해줘. 규칙 내용은:
- content는 280자 초과 금지(Post.MAX_CONTENT_LENGTH), 빈 값/null 금지, 검증은 도메인 생성자에서
- createdAt은 생성 시 고정(수정 불가)
- 계층별 규칙: domain은 JPA 엔티티+불변식(Spring 의존 없음), application은 @Service(쓰기에만 @Transactional),
  infrastructure는 JpaRepository
- HTTP 관심사(Controller/DTO)는 post 모듈이 아니라 apps/customer-api에
- 요청/응답 DTO는 record
```

## S4 — 항상 지킬 규칙은 paths 없이 (대조)

의존성 방향처럼 **어디서든** 지켜야 하는 규칙은 `paths:` 없이 둬서 항상 로드되게 합니다. S3(스코프된 규칙)과의 차이를 직접 비교해 보세요.

```
의존성 방향이나 모듈 경계처럼 어느 파일을 만지든 항상 지켜야 하는 구조 규칙은
.claude/rules/architecture.md로 따로 만들어줘. 이건 paths를 걸지 말고 항상 로드되게 해줘.
내용은:
- 의존성 방향: apps/* → modules/*,common / modules/* → common / 모듈 간 직접 의존 금지
- 도메인 모듈에 Spring Web 의존 추가 금지(POJO+JPA만)
- 새 모듈은 임의로 만들지 말 것(챕터에서 명시할 때만)
- 응답은 common의 ApiResponse로 감쌀 것
```

## 끝난 뒤 확인

- `CLAUDE.md` 생성됨 (짧은 헌법)
- `.claude/rules/post.md` — frontmatter에 `paths:` 있음 (post 만질 때만 로드)
- `.claude/rules/architecture.md` — `paths:` 없음 (항상 로드)
- 빌드는 변화 없음 (`./gradlew build` 그대로 통과)

> 다 끝내면 이 상태가 `v4.2-baseline`입니다. 막히면 `git checkout v4.2-baseline`으로 정답과 비교하세요.
