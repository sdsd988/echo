# echo 프롬프트 가이드 — 4-4 피드백 계층

> **진입:** `git checkout v4.4-baseline` (4-1 컨텍스트 + 4-2 조회 + 4-3 timeline까지 깔린 상태)
> 마지막 계층입니다. *틀린 걸 자동으로 잡아내는* 피드백 — 테스트·Hook·코드 리뷰. 그리고 4장 내내 만든 백엔드를 **화면으로** 봅니다.

---

## S1 — 모듈별 테스트 보강

피드백이 작동하려면 *잡아낼 테스트*가 있어야 합니다. 모듈에 단위 테스트를 추가합니다.

```
modules/post와 modules/timeline에 단위 테스트를 추가해줘.
- Post: content가 280자 초과거나 빈 값이면 IllegalArgumentException
- TimelineService: assemble가 최신순으로 정렬하는지
각 모듈 build.gradle.kts에 JUnit5 설정(testImplementation junit-jupiter, useJUnitPlatform)도 추가해.
```

---

## S2 — PostToolUse Hook으로 테스트 자동 실행

이제 Java 파일을 고칠 때마다 *그 모듈 테스트가 자동으로* 돌게 만듭니다. 실패하면 Claude에게 되돌려 고치게 합니다.

```
PostToolUse Hook을 설정해줘. Java 파일을 Edit/Write로 바꾸면, 그 파일이 속한 모듈의 테스트를
자동으로 실행하고 실패하면 그 내용을 너에게 돌려줘서 고치게 해.
- .claude/hooks/run-module-tests.sh 스크립트가 파일 경로로 모듈을 판별(post/timeline/user/customer-api)해 해당 테스트만 실행
- .claude/settings.json의 hooks.PostToolUse에 등록 (matcher: Edit|Write|MultiEdit)
- 테스트 실패 시 exit 2로 신호
```

> 시연 팁: 일부러 테스트를 깨는 코드를 넣어 저장해 보면, Hook이 실패를 잡아 Claude가 스스로 고치는 *피드백 루프*가 보입니다.

---

## S3 — Code Reviewer 서브에이전트 + /review

사람이 하던 코드 리뷰를 *전용 에이전트*에게 맡깁니다.

```
echo 전용 Code Reviewer 서브에이전트를 .claude/agents/code-reviewer.md로 만들어줘.
계층 규칙·모듈 경계(모듈 간 직접 의존 금지)·도메인 불변식(280자)·컨벤션(ApiResponse·record·패키지)·테스트 유무를
점검해서 "파일:라인 — 문제 — 제안" 형식으로 보고만 하게(코드 직접 수정 금지). 모델은 sonnet.
```

그런 다음 내장 명령으로 지금까지 변경분을 리뷰시켜 보세요:

```
/review
```

## S4 — 정적 HTML로 화면 마무리

4장 내내 만든 백엔드를 드디어 *화면으로* 봅니다. 프론트 스택 없이 HTML 한 장입니다.

```
apps/customer-api/src/main/resources/static/index.html에 정적 페이지 한 장을 만들어줘.
바닐라 JS fetch로:
- 글 작성 박스(280자 카운터 포함) → POST /posts
- 타임라인 영역 → GET /timeline 응답을 최신순으로 표시
응답이 ApiResponse라 data 필드를 꺼내 쓰면 돼. Spring Boot가 / 에서 그대로 서빙하니
브라우저로 http://localhost:8080/ 열어 확인.
```

## 끝난 뒤 확인

- `modules/post`·`modules/timeline`에 단위 테스트 + JUnit5 설정
- `.claude/hooks/run-module-tests.sh` + `.claude/settings.json` hooks(PostToolUse) — 편집 시 모듈 테스트 자동
- `.claude/agents/code-reviewer.md` 생성, `/review` 동작
- `static/index.html` — `localhost:8080/`에서 글 쓰고 타임라인 보임
- `./gradlew build` 통과

> 이게 **4장의 끝**입니다. 다 끝내면 이 상태가 `v5-baseline`(5장 진입점) — 4계층이 모두 깔리고 화면까지 도는 echo. 막히면 `git checkout v5-baseline`으로 비교하세요.
